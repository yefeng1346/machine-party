Couch play / v2.0

Machine Party local co-op & split screen

Machine Party v2.0 adds native couch co-op. Use the Local menu with up to four controllers, or combine three controllers with one keyboard-and-mouse player for a four-player session. Screen behavior varies by simulation, so it is not a fixed four-way split screen.

Can four people play on one PC right now?

Yes. Update Machine Party to v2.0 or later, open Local, choose Original, Custom, or Arcade, and have each player press a button in the lobby. A group of four can use four controllers, or three controllers plus one keyboard-and-mouse player.

The short answer

Does Machine Party support local co-op?

Yes. The v2.0 update adds native couch co-op for up to four players on one machine. Open the Local menu, choose Original, Custom, or Arcade, and let each player join from the lobby.

The official setup supports up to four controllers. For a group of four, one player can use keyboard and mouse while the other three use controllers. This is separate from the online private-room limit, which remains two to four players across their own game instances.

Screen layout

Is local play always split screen?

No. The v2.0 notes describe simulation-specific layouts rather than a single fixed format. Chisel Gauntlet switches between one screen and split screen depending on whether players are viewing the jumbotron. Duck Hunt splits the screen between the runners and the hunter, while Inside Job and The Filter work in split screen.

Minefield uses a camera that follows players based on their distance, and the other simulations generally behave like their online versions. Plan for a shared screen, dynamic camera, or split screen depending on the trial.

Controller planning

How many controllers are supported?

Connect up to four controllers for local play. A four-player group can also use three controllers and one keyboard-and-mouse player, so four controllers are not required.

Connect devices before opening the Local lobby, then press a button on each device to join. If a controller is missing or controls the wrong slot, disconnect extra input devices, test Steam Input, and use the controller troubleshooting guide before adding the rest of the group.

Start a local session

Couch co-op setup checklist

Use the official v2.0 Local flow:

  1. Update the game and make sure the host is running v2.0 or later.
  2. Connect up to four controllers before opening the game. For four players, one person may use keyboard and mouse instead.
  3. Open the main menu and choose Local.
  4. Select Original, Custom, or Arcade, then have each player press a button on their controller to join the lobby.
  5. Run a short simulation first. Check each player’s input and remember that the screen layout can change from one simulation to another.

If a device fails

What if a controller does not join?

Check the controller troubleshooting guide for missing or duplicated input. For a group that needs separate screens, switch to a private online room with one Machine Party instance per player; the multiplayer guide covers room IDs and Steam invites.

Remote streaming is not the same as native local co-op. Input ownership, latency, and simulation-specific controls can make it unreliable, so do not treat it as a guaranteed replacement for the Local menu.
