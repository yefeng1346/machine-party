Couch play / launch status

Machine Party local co-op & split screen

The launch build is online-first. The developers announced a late-August local co-op target, but the final same-PC controller count and screen layout still need to be confirmed by patch notes.

Checked August 6
  • Native local co-op: not in launch build
  • Split-screen layout: not documented
  • Online rooms: available for 2–4
Published August 1, 2026Last verified August 6, 2026Time-sensitive
Can four people play on one PC right now?

Not through the intended native local mode in the July 30 launch build. Machine Party's current supported group setup is an online room where each player joins from their own game instance.

The short answer

Does Machine Party support local co-op?

Not at launch. The developers said local co-op is planned for a late-August update after additional stability work. That statement is a target, not evidence that the feature is already available on every branch or storefront.

The Steam store's controller-support label means a controller can be used as an input device. It does not confirm that two, three, or four controllers can control separate players on one PC. Treat those as different questions.

Screen layout

Is there split screen?

There is no confirmed split-screen specification yet. The announcement says “local co-op” but does not say whether trials will use split screen, a shared camera, alternating views, or a mixture. Because Machine Party's minigames use different perspectives, the presentation may vary from one trial to another.

Until a patch note or in-game menu confirms the layout, do not promise a fixed four-way split screen to a couch group. A local mode can also be shared-camera co-op without being traditional split screen.

Controller planning

How many controllers are supported?

The exact same-PC controller limit has not been formally documented for the planned update. The game is designed for two to four players overall, but that number currently describes the online session rather than a guaranteed local device count.

If you are preparing a couch session, connect each controller directly, keep the same input type available for everyone, and wait for the update's setup screen to show how player slots are assigned. Do not buy four extra pads solely from the 2–4 player line on the store page.

When the patch ships

Couch co-op setup checklist

Use this as a practical checklist after the local feature is confirmed. The steps describe a sensible setup flow; they are not a claim that every menu already exists in the launch build.

  1. Update the game on the host PC and confirm that every player is running the same build.
  2. Connect the controllers before opening the game. If Steam Input is enabled, make sure each pad appears as a separate device.
  3. Open the multiplayer menu and choose the local, couch, or same-PC option if the update adds one.
  4. Have each player press the join or confirm input shown on screen. Check that each slot responds to the intended controller before starting a trial.
  5. Run one short minigame first. If a pad controls the wrong slot, close the lobby, reconnect devices in a predictable order, and test again.

Play today

What can a couch group do now?

If your group needs to play today, use a private online room with one person hosting and a separate Machine Party instance for each player. The multiplayer guide covers room IDs and Steam invites; the online fix checklist covers stale IDs, mismatched builds, and invite failures.

Remote streaming may work as an experiment, but it is not the same as native local co-op. Input ownership, latency, and minigame-specific controls can make it unreliable, so do not treat it as a guaranteed split-screen substitute.
