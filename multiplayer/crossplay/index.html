Online play / platform status

Machine Party crossplay: who can play with whom

Machine Party supports online co-op through Steam on Windows, Linux and Steam Deck. Cross-store and console crossplay is not officially documented, and cross-device room compatibility has not been independently verified.

Sources checked November 2, 2026
  • Steam online co-op: available
  • Steam Deck with PC: not independently tested
  • Console with Steam: not documented
Published November 2, 2026Sources checked November 2, 2026
Can I play with a friend on console?

There is no documented console version or console-to-Steam crossplay. If you are together, try local co-op on one PC.

Quick test

How to check crossplay in five minutes

  1. Update both Steam copies to the latest build and check that their versions match.
  2. Have one player create a private room and note its room ID.
  3. Invite the other player through Steam; if the invite fails, try the room ID.
  4. Start a short simulation and confirm both players appear in the same session.
  5. Record both version numbers and devices if the test fails.

Stream a local session

Using Remote Play Together instead of crossplay

Steam lists Remote Play Together for Machine Party. It streams the host’s local game to friends on supported devices, so it is a different setup from joining an online room on separate game copies. The host needs the game; invited friends do not need to own or launch it.

  1. Launch Machine Party from the host’s Steam library and open the Local mode.
  2. Have your friend sign in to Steam on a supported device.
  3. Open the Steam Overlay with Shift+Tab, right-click your friend in the friends list, and select Remote Play Together.
  4. After your friend accepts, join the local lobby and test each player’s controls in a short simulation.

Streaming quality and input latency depend on the connection; controller assignment may need adjustment. See Steam’s Remote Play instructions and the local co-op guide.

Troubleshooting

Crossplay errors and what they mean

Steam is not initialized

If the game says “Steam is not initialized,” close the game and restart Steam; launch the game from the Steam library; then verify installed files if the message persists. See the online fix guide for further checks.

Black screen

Use the black-screen guide to isolate a display or launch issue.

Second controller does not join

For local play, follow the second-controller checklist.
