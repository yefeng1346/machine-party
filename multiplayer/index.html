Connection bay / 2–4 subjects

Multiplayer setup

At launch, the reliable path is a private online room with people you already know. There is no public matchmaking, and couch play is scheduled for a later update.

Launch build
  • Private online rooms
  • No public matchmaking
  • No local co-op yet

Online private room

Play with Steam friends

  1. All players install the same current build and set Steam to online mode.
  2. The host creates a room from the game’s online menu.
  3. Share the numeric room ID shown in the lobby. Guests enter that ID through Join Room.
  4. If a Steam invite option appears, the host can also open the overlay with Shift + Tab, select a friend, and choose the available game invite action.
  5. Keep voice chat in Steam or Discord. Several trials depend on deception, timing, and reacting to your friends.

Couch play status

Local co-op & split screen

Not in the July 30 launch build. The developers announced that local co-op is planned for a late-August update. Until that patch is live, multiple players cannot join from one PC through the intended local mode.

Because the update has not shipped yet, final details such as whether every trial uses split screen, a shared camera, or a mix of layouts are not confirmed. Do not buy extra controllers solely for this mode until the patch notes state the supported setup.

Input devices

How many controllers?

The Steam store lists controller support, but the launch build is online-first: plan for one local subject and one active input device per PC. Machine Party supports two to four players overall. The exact same-PC controller limit for the upcoming local co-op update has not been formally documented.

If your single controller is not detected, connect it before launching, test Steam Input, and use the controller troubleshooting checklist.

Finding players

Is there online matchmaking?

No public quick-play or automatic matchmaking is available at launch. Players currently exchange room IDs in the Steam Community and use looking-for-group Discord channels. Treat publicly posted room IDs as temporary and never share account credentials.

Invite recovery

If the Steam invite is missing

  • Enter the game lobby before opening the Steam overlay; invite actions often appear only when the game is in a joinable state.
  • Use the numeric room ID instead. It is the most direct fallback.
  • Check Steam profile privacy: Game Details should be Friends Only or Public if friend-session visibility is failing.
  • Restart Steam for both host and guest after a client update.

Local co-op timing comes from the developers’ July 30 Steam announcement. It is a target, not a guarantee; check current patch notes before arranging a couch session.

Support matrix

  • Online private rooms: Yes
  • Players: 2–4
  • Room IDs: Yes
  • Steam friend invites: Lobby-dependent
  • Public matchmaking: No
  • Local co-op: Planned late August
  • Split screen: Not yet documented
  • LAN mode: Not confirmed
