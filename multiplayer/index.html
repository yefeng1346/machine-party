Machine Party multiplayer setup

The current build supports private online rooms with people you already know and native couch co-op on one PC. In-game public matchmaking and lobby lists are still not supported by the game's design.

Online private room

Play with Steam friends

  1. All players install the same current build and set Steam to online mode.
  2. The host creates a room from the game’s online menu.
  3. Share the numeric room ID shown in the lobby. Guests enter that ID through Join Room.
  4. If a Steam invite option appears, the host can also open the overlay with Shift + Tab, select a friend, and choose the available game invite action.
  5. Keep voice chat in Steam or Discord. Several trials depend on deception, timing, and reacting to your friends.

Couch play status

Local co-op & split screen

Available in v2.0 and later. Open Local, choose Original, Custom, or Arcade, and have each player press a button in the lobby. Up to four controllers are supported, or three controllers plus one keyboard-and-mouse player for a group of four.

The screen layout varies by simulation. Chisel Gauntlet can use one screen or split screen, Duck Hunt divides the screen between runners and hunter, and Inside Job and The Filter work in split screen. Minefield uses a distance-based camera.

Input devices

How many controllers?

Local mode accepts up to four controllers. One player can use keyboard and mouse, which means a four-player group needs only three controllers.

If a controller is not detected, connect it before launching, test Steam Input, and use the controller troubleshooting checklist.

Finding players

Is there online matchmaking?

There is no in-game public matchmaking or lobby list. The developers direct solo players to the official Looking For Group Discord; private room IDs and Steam invites remain the normal in-game path. Treat publicly posted room IDs as temporary and never share account credentials.

Platform support

Does Machine Party support crossplay?

Machine Party is currently documented as a Steam release, and the developers have not announced cross-platform or cross-store multiplayer with consoles, Epic Games Store, or itch.io.

Playing the native Linux build or using Steam Deck still connects through the Steam edition, so that is not separate console-style crossplay.

Invite recovery

If the Steam invite is missing

  • Enter the game lobby before opening the Steam overlay; invite actions often appear only when the game is in a joinable state.
  • Use the numeric room ID instead. It is the most direct fallback.
  • Check Steam profile privacy: Game Details should be Friends Only or Public if friend-session visibility is failing.
  • Restart Steam for both host and guest after a client update.
