Couch co-op / input setup

Machine Party four-player couch co-op

Plan a full couch session on one computer: choose the input arrangement, check all four players, and test the screen before the first longer game.

Start here
  • Four distinct player seats
  • 4 pads or 3 pads + keyboard/mouse
  • Test one short round first
Published November 1, 2026Sources checked November 1, 2026By Machine Party Wiki Editorial Team
What do four local players need?

Use four controllers, or three controllers plus one keyboard-and-mouse player. Connect the devices to the same PC, enter Local mode, and confirm four distinct player seats before readying up. Four players is the documented ceiling.

Choose the four-player input arrangement

Decide who uses which device before launching. If one friend is comfortable with keyboard and mouse, that seat saves a controller. Keep the mouse accessible rather than placing a keyboard alone on the sofa, because the documented arrangement includes both.

Test the game on the screen you intend to use. This is especially useful when moving from a desk monitor to a TV: confirm that the display and audio work before adding several players and controllers. A larger screen helps with reading, but it does not change the number of supported seats.

Keep a short list of the pads and connection types. Labeling them A, B, C, and D during setup is often easier than troubleshooting four identical devices from memory. A wired test can help isolate a wireless problem; it is a diagnostic comparison, not a requirement to buy extra equipment.

Build the lobby one player at a time

  1. Let Steam finish updates before the group arrives. Use the current available build rather than stopping at the original couch co-op release.
  2. Connect the chosen devices before launching. Start with devices that have already passed Steam’s controller input test.
  3. Choose Local, then Original, Custom, or Arcade.
  4. Let one controller join at a time from the lobby. Associate each visible player with a physical device before adding the next person.
  5. If using keyboard and mouse, follow the current lobby prompts for that seat. Complete the displayed player setup for everyone.
  6. Count four distinct players. Take turns checking input, then have the group ready up.

A menu accepting input from several pads is not a substitute for counting joined players. This check catches the common situation where the last pad can navigate a shared interface but has not created a separate seat.

Check the TV and local screen layout

Do a brief round before settling into a long session. All four people should be able to read the briefing from their seats and identify their player once the simulation begins. If text or edges are cut off on the TV, compare with the PC monitor and check the TV’s picture-sizing controls before changing controller mappings.

Do not expect four equal viewports in every simulation. The game adapts its camera to the trial, so a shared view can be normal. The local co-op and split-screen guide owns the simulation-by-simulation explanation.

If the entire display remains black, test with one controller first and use the black-screen troubleshooting guide. Adding more players cannot establish whether the display itself is rendering correctly.

If the third or fourth player cannot join

Close the game before unplugging and rearranging devices during diagnosis. First prove that the suspect pad works by itself. Then rebuild the lobby in the same order and note exactly which addition changes the result.

If the failure follows one physical controller, compare that controller’s cable, wireless connection, and Steam input test. If any controller fails only when several devices are present, check virtual pads and translation tools before replacing hardware. Use the second-controller and missing-seat checklist for that comparison.

If one device creates two seats, stop adding players and use the controller double-input guide. Keep the intended total within four; connecting another keyboard does not establish a fifth supported seat.

Handle a controller disconnect during setup

If a pad disconnects, stop and note whether the game stays open, loses one player, or exits completely. Those are different symptoms. Recreate the lobby after reconnecting rather than assuming a reconnected pad has kept its previous seat.

The developer’s August 13 v2.1.1 notes report a fix for a potential crash when a controller disconnected in the Local lobby. Update before diagnosing that older failure. The fix does not prove every modern wireless disconnect or missing seat has the same cause.

When reporting a repeatable problem, include the build, number of players, device models, connection types, and whether a keyboard-and-mouse seat was in use. State which device was added or removed immediately before the failure.

Four-player couch questions

Can we play with only three gamepads?

Yes, if the fourth person uses keyboard and mouse. For the first mixed-input test, use the linked keyboard-and-controller guide before adding the rest.

Does everyone need their own computer?

For this Local setup, devices connect to one PC. Friends playing from separate computers should use the online setup guide.

Can we add a fifth couch player?

The documented maximum is four. This guide does not recommend mods, extra keyboards, or virtual pads as a supported way around that limit.
