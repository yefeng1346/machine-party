Machine Party matchmaking & LFG

There is no automatic public matchmaking queue in the launch build. Machine Party expects you to host or join a private room with a code shared by friends or a community group.

Does Machine Party have matchmaking?

No public automatic matchmaking is available at launch. You need a private room ID or a Steam invitation from someone already hosting a lobby.

How the lobby works

Private rooms replace quick play

The host creates a room and receives a long numeric ID. Guests enter that ID through Join Room. A complete session needs two to four players; the game does not currently fill empty slots with strangers or advertised bots.

This setup is fast when everyone already knows one another, but it creates an extra step for solo players. Public Steam discussions often contain temporary room IDs, and community LFG groups organize sessions outside the game.

Finding a group

Where to look for players

  • Steam Community discussions: look for current looking-for-group posts or recent room IDs.
  • Community Discord servers: use channels dedicated to Machine Party or Klubnika games.
  • Your Steam friends list: invite people after creating a lobby, or send the room ID directly.
  • Existing gaming groups: Machine Party works best when voice chat and familiar rivalries are already part of the session.

A room ID can expire when the host leaves or recreates the lobby. Prefer a live conversation over copying a number from an old post.

Safety

Share only what the lobby needs

A numeric room ID is enough to attempt joining. Never give another player your Steam password, account recovery code, session cookie, private IP address, or remote-control access. A legitimate host does not need those details.

When joining strangers, use Steam’s blocking and reporting tools if someone becomes abusive. Voice chat through a moderated community can be easier to control than sharing a personal server invitation publicly.

Future changes

Will public matchmaking be added?

No official launch announcement reviewed for this page promises a matchmaking update. Players have requested it, but a request is not a roadmap. This page will change only after the developer or patch notes confirm a new queue or server browser.
