Machine Party black screen fix: start here

Update the graphics driver, verify the Steam files, remove unofficial launch options or replacement DLLs, and test overlays one at a time. If the problem is specifically a failed private room, invalid room ID, or missing Steam invite, go straight to the Machine Party online fix guide.

Common problems

Open an issue for a short, ordered checklist. Stop once the problem is gone.

Room ID fails or multiplayer will not connect

Use the dedicated online multiplayer fix guide for the full room, invite, firewall, version, and host-switching checklist.

  1. Confirm the host is still in the lobby and create a fresh room.
  2. Copy the complete numeric ID with no spaces, then test with one guest.
  3. Update the game, restart Steam, and allow the genuine game and Steam through the firewall.

There is no in-game public matchmaking fallback; use a valid private room or the official Looking For Group Discord.

Controller is connected but not recognized
  1. Connect the controller before launching the game and close other controller-mapping tools.
  2. In Steam, open Library → Machine Party → Properties → Controller. Test the default setting first, then try enabling Steam Input.
  3. For an Xbox-compatible pad, also test with Steam Input disabled; double translation can cause missing or repeated inputs.
  4. Disconnect extra pads, wheels, virtual controllers, and handheld companion devices, then relaunch with one controller.
  5. Confirm the controller works in Steam’s own input test.

In the current build, local co-op is still not available, so plugging in several controllers will not create several local subjects.

Game crashes on launch or during a round
  1. Steam Library → right-click Machine Party → Properties → Installed Files → Verify integrity of game files.
  2. Install the latest stable graphics driver, then restart the computer.
  3. Disable overlays one at a time: Discord, GPU recording, performance monitoring, and third-party injectors.
  4. Make sure the GPU supports Vulkan. The official minimum requirements explicitly require Vulkan support.
  5. Try a clean reboot and close heavy background applications. The Windows minimum lists 8 GB RAM.

v1.5 renderer option: Start with the normal launch option. If graphics still fail, try the separate Direct3D 12 launch option from Steam.

If one specific minigame always crashes, include its name in the bug report.

Machine Party Black Screen Fix
  1. Wait only while the game is still responding; close a permanent black screen instead of leaving it running indefinitely.
  2. Update the graphics driver from Nvidia, AMD, or Intel rather than relying only on Windows Update, then restart the PC.
  3. Verify game files and remove any unofficial launch options, injectors, or replacement DLL files.
  4. Press Alt + Enter once to test windowed mode if the game responds but the display stays black.
  5. On laptops, force the game to use the discrete GPU through Windows Graphics settings.
  6. Disable overlays and recording filters one at a time, then check the pinned “Temporary fix for graphical issues” thread in the Steam discussions for the developer’s newest workaround. Version 1.5 also updated Godot to 4.5.2 and added a Direct3D 12 launch option; start with normal mode, then test D3D12 only if the graphics issue persists.

If the screen is black immediately after an update, verify the files before reinstalling the entire game.

Steam invite option does not appear
  1. Create the in-game room first, then open the overlay with Shift + Tab.
  2. Use the in-game numeric room ID if the overlay still offers no invite action.
  3. Make sure Steam Overlay is enabled for both Steam and Machine Party.
  4. Set Steam Profile → Privacy Settings → Game Details to Friends Only or Public.
How to report a bug to the developers

Use the pinned “Bugs & Issues — Report them here” discussion. Include:

  • A one-line summary and the exact minigame or menu where it happened.
  • Steps that reproduce the problem.
  • Expected result versus what actually happened.
  • Windows or Linux version, CPU, GPU, RAM, controller model, and game version.
  • Whether you were host or guest and how many players were connected.
  • A screenshot, short video, and the latest game log if available.

Do not post passwords, Steam login details, private IP addresses, or another player’s personal information.
