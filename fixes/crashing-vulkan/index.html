Launch maintenance / PC

Machine Party crashes & Vulkan errors

Start with files, drivers, and the official requirements. Avoid registry edits, random launch flags, or replacing system DLLs unless the developer publishes a specific instruction.

Official minimum
  • Windows 11 / 64-bit
  • 8 GB RAM
  • Vulkan support required

Start with three checks

Verify the Steam files, install the current stable graphics driver, and confirm the active GPU supports Vulkan. Restart the PC after the driver update before testing again.

Safe sequence

Game crashes at launch

  1. Steam Library → right-click Machine Party → Properties → Installed Files → Verify integrity of game files.
  2. Install the current stable driver directly from Nvidia, AMD, or Intel for the GPU actually running the game.
  3. Restart Windows after the driver installation.
  4. Disable nonessential overlays one at a time: Discord overlay, GPU recording, performance monitoring, and third-party injectors.
  5. Remove unofficial launch options while testing.
  6. On a laptop, set Machine Party to the high-performance discrete GPU in Windows Graphics settings.

Stop when the problem is gone. Re-enable optional software one item at a time so the conflicting layer becomes clear.

Vulkan

What “Vulkan support required” means

Machine Party’s official Windows requirements explicitly require Vulkan support. A GPU model can be physically capable while an old, incomplete, or generic driver fails to expose the required Vulkan components. That is why installing the vendor driver matters more than relying only on Windows Update.

The Windows minimum lists a Radeon RX 6500 XT or Nvidia GTX 1660, a dual-core 2.4 GHz processor, 8 GB RAM, Windows 11, and 1 GB of storage. Meeting those lines does not guarantee that every crash is hardware-related, but a system below them is outside the advertised minimum.

Visual failures

Black screen or broken graphics

  • Wait through the first launch only if the process is still responding; do not leave a permanent black screen running indefinitely.
  • Use Alt + Enter to test windowed mode when the game responds but the display is wrong.
  • Verify that the monitor is connected to the discrete GPU rather than a motherboard output on a desktop PC.
  • Disable overlays and recording filters that inject into the renderer.
  • Verify files after any interrupted update.

Round-specific crash

One minigame always crashes

Record the exact minigame name, what happened immediately before the crash, whether you were host or guest, the player count, and whether the same round fails after verifying files. A reproducible trial-specific crash is more useful to the developer than a generic “game crashed” report.

Include Windows version, CPU, GPU, RAM, driver version, game version, and any overlays. Attach a short video or log only if the official bug-report channel requests it, and remove personal information first.

Avoid bad advice

Do not download random DLL files

Replacing Vulkan or system DLLs from an unofficial download can create security problems and make the original issue harder to diagnose. Do not disable the firewall, antivirus, or Windows security permanently. If a temporary test changes the result, restore protection and create a narrow exception only for a trusted program.
