How to play Machine Party

Start with the rule card, not muscle memory. Machine Party changes controls between trials, and the short briefing before each round tells you exactly which inputs are active.

First-session rule
  • Read the entire briefing
  • Check the control icons

Host flow

Create a room

  1. Launch the game through Steam while Steam is online.
  2. Choose the online or host option from the main menu and create a private room.
  3. Wait for the lobby to display its long numeric room ID. Copy it carefully.
  4. Send the ID to two or three friends, or invite them through the Steam overlay if the lobby exposes an invite action.
  5. Confirm every subject has loaded, choose your trial selection, and start the session.

Guest flow

Join a room

  1. Get the room ID directly from the host. Machine Party does not currently provide public matchmaking.
  2. Open the join-room option from the main menu.
  3. Paste or type the complete numeric ID without spaces, then submit.
  4. If the room cannot be found, ask the host to recreate it and send the new ID. Also confirm both players are on the same game version.

Before the timer starts

Read the briefing

Each minigame has its own objective and may replace normal movement with a rhythm, timing, aiming, or assembly control scheme. The briefing screen answers three things: what you can do, what kills you, and what counts as winning. If a button icon in this guide disagrees with that screen, follow the screen.

Quick start

  1. Use Steam online mode.
  2. Host a private room.

  4. Bring 2–4 total players.
  5. Read every round prompt.
